# NIALORA — web

Niasinamid içeren, çift fazlı diş macunu NIALORA'nın tek sayfalık tanıtım ve satış sitesi (TR/EN).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

Stack: Vite · React 19 · TypeScript · Tailwind v4 · Framer Motion · Lenis.
