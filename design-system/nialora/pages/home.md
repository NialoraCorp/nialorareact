# Nialora — Home page overrides

> Overrides `MASTER.md` (generated by UI UX Pro Max). The brand document
> ("NIALORA Ürün Bilgi Dokümanı", Oct 2026) and the product films take
> precedence over the generic recommendation.

## Pattern
Scroll-Triggered Storytelling (kept from MASTER): Hook → Story → Two-phase
chapter → Ingredients → Ritual → Film → Climax CTA (Buy).

## Style
"Skincare editorial" instead of Liquid Glass: ivory / blush backgrounds,
soft studio light, marble-like calm, gold hairlines, generous whitespace,
few words. Glass is used only for the sticky nav (backdrop blur).

## Colors (brand)
| Token | Value | Use |
|---|---|---|
| `--color-ivory` | `#FBF7F2` | page background |
| `--color-pearl` | `#FFFDFB` | cards |
| `--color-blush` | `#F6E6E8` | hero / section tint |

| `--color-turquoise` | `#7FD1D6` | turquoise phase |
| `--color-teal` | `#1F5F66` | turquoise phase text contrast |

Two phase colors appear only where the two-phase story is told. Never more
than gold + the two phases on one screen.

## Typography
Cormorant Garamond (display, 300–500, italic) + Montserrat (UI/body 300–500).
Eyebrows: Montserrat 11–12px, tracking 0.3em, uppercase.

## Motion
Framer Motion only. Easing `cubic-bezier(0.22, 1, 0.36, 1)`, durations
0.8–1.2s for reveals, scroll-linked transforms with light springs. Lenis
smooth scroll. Respect `prefers-reduced-motion` (MotionConfig `user`).

## Claim rules (hard constraints from the brand document)
Allowed: çift fazlı formül · niasinamid içerir · florürlü · nane ferahlığı,
uzun süren serinlik · ışıltılı jel görünümü · dişleri temizler · 100 g ·
premium diş macunu deneyimi.

"dermatolojik/klinik test edilmiştir", "premium formül / premium içerik",
"SLS içermez", "alkol içermez", "Bakanlık / TİTCK onaylı", competitor names,
